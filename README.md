# DEAD-LINE II Mod Loader (DLML)
This is a functioning mod loader for the game **DEAD-LINE II** created by **rasen46** and **K4PUKA**.

Currently: v0.9 pre-release

How to import mods:
Use the import button to import .luas. These files are created by mod developers. More info on how to create .lua files for developers coming soon.
